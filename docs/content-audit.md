## 二、年龄标注抽检

- 3–4 岁：熟悉动物、自然现象、数字 0–9、声母与四声、短篇故事、简单歌谣、前 6 页安静书。
- 5–6 岁：生活常识、身体/常用字、10–20、韵母/整体认读/易混声母、七言及较长古诗、抽象脑筋急转弯、进阶安静书。
- `npm run check:counts` 会校验每个栏目同时存在两个年龄段，并检查 `src/data/ages.ts` 里的 id/分组没有写错。

## 三、遗留风险

- 古诗文本存在异文（如「返景」/「返影」），本轮采用教材常见版本；如家长使用特定教材，以教材为准。
- 动物叫声、食性等为幼儿简化表述，不覆盖全部物种；后续新增内容需继续遵守「不确定就不加」。
- 本轮未做方言、少数民族语言或特殊教育适配。
